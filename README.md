# ChatGPTの長文がパッとわかる！5つの魔法の合い言葉（特典ページ）

Instagramリールのコメント特典として配布する、1ページ完結型のWebページです。
GitHub Pagesで無料公開できる、HTML・CSS・JavaScriptだけの静的サイトです
（ビルド作業・データベース・ログイン機能は一切ありません）。

このページは `mion-ai-mama/instagram-tokuten-template` というテンプレートリポジトリを
「Use this template」で複製して作成しました。今後さらにこのリポジトリを複製して
別の特典を作る想定はありません（次に新しい特典を作るときは、テンプレート本体
`instagram-tokuten-template` の方を複製してください）。

## 2. ローカルでの確認方法

1. このフォルダをパソコンにダウンロード（またはクローン）する
2. `index.html` をダブルクリックしてブラウザで開く

サーバーを立てたい場合は、フォルダの中で以下を実行しても確認できます。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## 3. ファイル構成と編集する場所

| ファイル | 説明 | 編集頻度 |
|---|---|---|
| `js/content.js` | ページの文章・プロンプト・リンクをまとめたファイル | 文章を直すときはここ |
| `assets/images/` | 画像ファイルの置き場所 | 画像を差し替えるときだけ |
| `index.html` の `<head>` 内 | SEO・OGP用の説明文 | `content.js` の `meta` を変えたら合わせて確認 |
| `css/style.css` | 色やデザイン | 基本的に編集不要 |
| `js/script.js` | ページの動き（コピー機能・アコーディオンなど） | 基本的に編集不要 |

## 4. content.js の編集方法

`js/content.js` をテキストエディタ（メモ帳や、GitHub上の鉛筆アイコンでも可）で開くと、
日本語の文章が並んでいます。`"　　"`（ダブルクォーテーション）で囲まれた部分だけを
書き換えてください。

**触ってはいけない部分**: `:`（コロン）／`,`（カンマ）／`{ }`（波かっこ）／
`[ ]`（角かっこ）／`<br>` や `<code>` などのHTMLタグ（残したまま、前後の文字だけ変える）

- `troubleshoot.items` の中の1項目だけ `fixText` はあるのに `buttonText` が
  `null` になっている箇所があります（「内容や文字が間違っている」の例文）。
  これは〇〇・△△の部分を毎回書き換えて使う「例」のため、意図的にコピーボタンを
  付けていません。

保存したら `index.html` をブラウザで開けば、変更が反映されているか確認できます。

## 5. CTAリンクの変更方法

ページ最後のCTAボタン（『AIマネタイズの教科書』LINE登録バナー）のリンク先は、
`content.js` の `cta.buttonUrl` の1か所だけを変更すれば反映されます。

```js
cta: {
  ...
  buttonUrl: "https://example.com/", // ← ここをLINE登録URLなどに変更
  bannerImage: "assets/images/cta-banner.png",
  bannerAlt: "（バナー画像の内容を説明する文章）",
},
```

## 6. OP画像の差し替え方法

1. `assets/images/` フォルダに新しい画像を入れる
2. `content.js` の `heroImage.src` と `heroImage.alt` を書き換える
3. OGP画像として使う場合は、`meta.ogpImage` も**`https://`から始まる絶対URL**で
   更新し、`index.html` の `<head>` 内にある `og:image` タグも同じ内容に合わせる
   （検索エンジンやSNSのクローラーはJavaScriptを実行しない場合があるため）

## 7. GitHub Pagesで公開する方法

1. GitHubでこのリポジトリを開く
2. 上部メニューの「Settings」→ 左メニューの「Pages」を開く
3. 「Build and deployment」の「Source」で「Deploy from a branch」を選ぶ
4. 「Branch」で「main」と「/ (root)」を選び、「Save」をクリックする
5. 数分待つと、ページ上部に公開URLが表示される
   （例：`https://mion-ai-mama.github.io/chatgpt-5-keywords-tokuten/`）

> 💡 このリポジトリに変更をpushするたびに、GitHub Pagesは自動で更新されます。

## 8. 公開後のURLの確認方法

1. GitHubのリポジトリ画面 →「Settings」→「Pages」を開く
2. 「Your site is live at ～」という緑色の表示のURLをコピーする
3. ブラウザで開いて公開状況を確認する
4. Instagramのプロフィール欄やリンク集ツールにそのURLを貼り付ける

## 9. 公開前チェック項目

- [ ] すべてのコピーボタンが正しい文章をコピーできる
- [ ] 日本語の文字化け・誤字脱字がない
- [ ] 375px幅のスマートフォン表示で横スクロールが発生しない
- [ ] OP画像が切れずに表示される
- [ ] PC・スマートフォンの両方でレイアウトが崩れない
- [ ] ページ内リンク（「事前設定文へ戻る」ボタンなど）が正しくスクロールする
- [ ] `content.js` の `cta.buttonUrl` が実際のLINE登録URLになっている
- [ ] ブラウザのコンソール（検証ツール）にエラーが出ていない
- [ ] GitHub Pagesで画像・CSS・JavaScriptが正しく読み込まれている

## 10. よくあるエラーと対処方法

| 症状 | 原因の可能性 | 対処方法 |
|---|---|---|
| ページが真っ白になる | `content.js` の書き方に誤り（カンマの消し忘れなど） | 直前に保存した内容に戻し、1か所ずつ変更して確認する |
| 文章が反映されない | ブラウザのキャッシュが残っている | スマホ・PCともに再読み込み（強制リロード）する |
| コピーボタンが反応しない | ページを`file://`で直接開いている | GitHub Pages公開後のURL（`https://`）で確認する |
| アコーディオンが開かない | 古いブラウザで`<details>`タグ未対応 | 最新のブラウザ（Chrome・Safari・Edge）で確認する |
| 公開URLが404になる | GitHub Pagesの設定がまだ反映されていない | 数分待ってから再度アクセスする |
| 画像が表示されない | ファイル名の大文字・小文字違い | `assets/images/` 内の実際のファイル名と `content.js` の記載を見比べる |

## 技術的なメモ

- ビルド（変換作業）は一切不要です。HTML・CSS・JavaScriptだけで動く「静的サイト」です
- React・Next.js・Vue・データベース・サーバーは使用していません
- 外部の有料サービスへの依存はありません
- コピー機能は Clipboard API を使用し、非対応環境向けのフォールバックも実装しています
- 「うまくいかないとき」のアコーディオンは `<details>`/`<summary>` タグで実装しており、
  追加のJavaScriptなしでキーボード操作にも対応しています
